# KITSTONE / Абакан — демонстрационный сайт

Одностраничный адаптивный сайт с тёмным промышленным визуальным стилем, карточками продуктовых направлений и формой коммерческого запроса. Заявки сохраняются в локальную SQLite-базу.

## Важно перед показом директору

Это демонстрационная концепция, а не официальный опубликованный сайт. В открытых источниках удалось подтвердить существование ООО «КИТСТОУН» в Абакане и наличие в видах деятельности производства керамической плитки и кирпича, а также публичное упоминание проекта керамзитового завода. При этом не удалось подтвердить официальный сайт компании, её утверждённый каталог, актуальные цены, технические характеристики, телефон отдела продаж или фотографии именно её производственной площадки.

Поэтому:
- карточки продукции и тексты намеренно не содержат неподтверждённых цен, марок, объёмов производства и обещаний качества;
- фотографии в интерфейсе загружаются с Unsplash и служат только визуальными заглушками, не изображают подтверждённо завод «Китстоун»;
- перед публикацией замените фотографии собственными снимками завода, продукции, погрузки, лаборатории и складских запасов;
- подтвердите ассортимент, характеристики, адрес производства, телефон, почту, минимальный заказ и географию поставок;
- добавьте утверждённую политику обработки персональных данных и юридически корректное согласие в форме.

## Требования

- Node.js 20 или новее
- npm

## Запуск локально

1. Распакуйте проект.
2. Откройте терминал в папке проекта.
3. Выполните:

   ```bash
   npm install
   ```

4. Скопируйте `.env.example` в `.env` и задайте `ADMIN_TOKEN` длинным случайным значением.
5. Запустите:

   ```bash
   npm start
   ```

6. Откройте `http://localhost:3000`.

База данных создаётся автоматически в `data/kitstone.sqlite` после запуска сервера. Не удаляйте этот файл, если хотите сохранить заявки.

## Получение заявок

Для локальной проверки можно открыть DevTools браузера и отправить форму. Записи попадут в SQLite.

Список последних заявок доступен через защищённый API:

```bash
curl -H "X-Admin-Token: ВАШ_ADMIN_TOKEN" http://localhost:3000/api/leads
```

Обновить статус заявки:

```bash
curl -X PATCH http://localhost:3000/api/leads/1/status \
  -H "Content-Type: application/json" \
  -H "X-Admin-Token: ВАШ_ADMIN_TOKEN" \
  -d '{"status":"В работе"}'
```

Допустимые статусы: `Новая`, `В работе`, `Коммерческое предложение`, `Закрыта`.

## Перед публикацией в интернете

- Установите уникальный `ADMIN_TOKEN`, не храните `.env` в Git.
- Используйте хостинг с HTTPS и резервным копированием базы данных.
- SQLite подходит для прототипа и небольшого сайта на одном сервере; для высокой нагрузки или нескольких серверов рассмотрите PostgreSQL.
- Подключите уведомления менеджеру (например, Telegram или корпоративную почту), мониторинг и защиту от спама.
- Проверьте требования к персональным данным, срок хранения заявок и порядок удаления данных.
- Не публикуйте юридический адрес как адрес завода, пока компания не подтвердит это отдельно.
